# Meridian design system

Reference: the generated primary screen at `docs/design/primary-screen.png`.

White main canvas, pale grey-green sidebar (#f1f5f2), forest green accent (#183f35), thin divider rules. Times editorial serif with DM Sans UI text, system Chinese fallbacks. Fixed 244px navigation; main reporting column and 393px evidence rail. Open lists and rails, with no card grid. Simple Lucide outline icons; filled bookmark only for saved state. Dotted map is an editorial motif, not live geospatial data.

Primary surface: Daily briefing / News stream / Saved stories / Sources & status. Six interest categories. Daily 08:00 Eastern schedule. Source ledger and story/briefing detail dialogs follow the same typography and divider system. Mobile uses a navigation drawer; the daily overview appears before the news list.

Allowed primary copy: MERIDIAN, A wider view of the world., Your daily briefing. Clear context. Traceable sources., THE LEAD, Read the briefing, Latest reporting, Briefing notes, What changed, What to watch, Source coverage, View source ledger, Refresh feeds. Real dates, feed status, current headlines and prepared analysis replace illustrative concept content. English / 双语 / 中文 adds the user's bilingual requirement. All source counts and collection statuses derive from real data.

No news illustrations or photos are required. This interface uses code-native typography, controls and an illustrative vector map. The concept is retained as a design reference rather than embedded UI.
